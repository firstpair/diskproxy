# Manual editions

The canonical manual is [`../diskproxy-manual.md`](../diskproxy-manual.md). The root [`book.build.json`](../../book.build.json) drives the shared FirstPair builder. [`../../FIRSTPAIR.md`](../../FIRSTPAIR.md) records source ownership, clean/pushed provenance, verification and publication commands.

PDF, EPUB, single-file HTML, split chapter HTML and the version manifest are generated in the repository's `dist/`. They are complete manual editions, distinct from the project story in [`../diskproxy-blog.md`](../diskproxy-blog.md). Reader styling and the export-only source-link filter live here; the filter does not modify the manuscript.
